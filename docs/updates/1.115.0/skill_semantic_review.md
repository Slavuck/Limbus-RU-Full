# Независимая смысловая вычитка новых навыков

Помимо проверки тегов и чисел, описания ID 8470–9144 сопоставлены с корейским оригиналом отдельным переводчиком. Уточнения внесены в применяемые словари:

- ID 8631: условие расхода — 10+ счётчика Заряда, не его потенциала. В EN слово Count пропущено.
- ID 8687: счётчик повышается до 15, не прибавляется на величину до 15. Эффект за прирост рассчитывается за каждые 5 единиц.
- ID 8857: аналогичное восполнение счётчика до 10; Уязвимость даётся за каждые 2 единицы прироста.
- ID 8910, 9105, 9108: явно указан расход счётчика Заряда по KR; EN опускает Count.
- ID 8963, 8965, 8968, 8971, 8973, 8977: финальный эффект распределяется между врагами среди целей атаки. В EN enemy пропущено; ограничение существенно при Коррозии, когда сама атака может поражать союзников.
