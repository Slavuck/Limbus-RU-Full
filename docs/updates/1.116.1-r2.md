## Повторная рекурсивная проверка

Скрипт не меняет оригиналы или перевод. Он нормализует префиксы EN_/KR_, сопоставляет записи по ID/ключам, проверяет пропущенные файлы, записи, поля и переводы, теги, подстановки и технические значения. Совпадения с исходником отделяются от подтверждённых названий и клавиш. Параметр `--baseline-index` включает проверку изменений существующих строк, а `--baseline-manifest` — побайтовые изменения всех файлов EN/KR, включая корейские файлы без английского соответствия.

```powershell
python scripts/audit_source_update.py --en "путь/Localize/en" --kr "путь/Localize/kr" --ru Localize/Limbus-RU-Full --target-version 1.116.1-post-2026-10-04 --report-dir reports/current --prior-queues docs/updates/1.116.1-r2/review_decisions.jsonl --mode full-review --check
```

Для принятия подтверждённых решений этого выпуска скопируйте `docs/updates/1.116.1-r2/review_decisions.jsonl` в каталог отчёта перед запуском. Для инкрементального сравнения дополнительно передайте сохранённые `source_index.jsonl` и `backup_manifest.json` предыдущего аудита. Большие исходные индексы и резервные копии хранятся в рабочем каталоге, в релизный ZIP не включены. По умолчанию локальный рабочий скрипт также умеет читать пути из `input/расположение языковых пакетов.txt`.

Архив `Limbus-Ru-Full.zip` содержит `Limbus-RU-Full/` и `config.json` в корне. Игровая проверка отображения не выполнялась.
