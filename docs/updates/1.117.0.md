# Обновление 1.117.0 — 16 октября 2026 года

Обновление подготовлено по установленным EN/KR после обновления игры от **15 октября 2026 года (KST)** и его хотфикса. База сравнения — опубликованная версия русификатора 1.116.2 от 11 октября. Текущий `output` до начала работы совпадал с опубликованным пакетом по содержимому JSON и шрифтов.

## Рекурсивная сверка

Проверены 2370 английских, 2413 корейских и 2370 русских JSON; индекс содержит 271604 исходных строковых поля. Обработаны 812 текстовых полей в 33 файлах, из них 8 файлов новые. Для 304 полей использован единственный совместимый прежний перевод по точной паре EN/KR либо синхронизация изменившегося цвета разметки. Остальные строки переведены или проверены по смыслу; повторы переводились согласованно.

Итог: **0** пропусков структуры, отсутствующего или непереведённого текста, ошибок подстановок, тегов, разметки, технических значений и устаревших русских записей. 53 файла только KR и 10 только EN существовали до обновления: они перечислены в `file_pairing.json`; новых расхождений парности нет. Проверяются также хеши всех файлов KR, включая файлы без EN-пары. Разрешённые названия, символы и технические теги не считаются непереведённой прозой.

Скрипт `scripts/audit_game_update.py` сохраняет полный индекс для следующего обновления и отдельные отчёты по новым, изменённым, удалённым, непереведённым и устаревшим строкам. В этом выпуске устранено ложное требование переводить технический идентификатор модели при изменении только корейского варианта. Совпадение технического значения с EN по-прежнему проверяется.

```powershell
python scripts/audit_game_update.py --en <папка_EN> --kr <папка_KR> --ru Localize/Limbus-RU-Full --baseline-index <предыдущий_source_index.jsonl> --baseline-manifest <предыдущий_source_manifest.json> --target-version <версия> --report-dir <отдельная_папка_отчёта> --mode full-review --check
```

Машинные отчёты и решения по строкам находятся в [папке выпуска](./1.117.0/). Исходники и перевод при аудите не изменяются. Локальный полный индекс сохранён в `work/release-1.117.0/after/source_index.jsonl`; он не публикуется из-за размера.

## Пакет

`Limbus-Ru-Full.zip` содержит `config.json` в корне и папку `Limbus-RU-Full` с переводом и шрифтами. Проверены CRC, отсутствие лишних путей и SHA-256 каждого файла относительно `output`. Параллельная редакторская инфраструктура не менялась. Проверка отображения в запущенной игре не выполнялась.

Все 54 автоматические проверки репозитория прошли, включая регрессии технических имён, условия преображения Синклера и уточнённые эффекты Даров.
