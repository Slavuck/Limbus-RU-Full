## Рекурсивное сравнение

Оригинальные EN/KR из установленного клиента Steam использовались только для чтения. До обновления было 2 266 русских файлов; найдено 96 новых EN-файлов, 4 424 непереведённых строковых поля, 244 структурных и 56 технических расхождений. Повторяющиеся тексты объединены в 2 928 уникальных переводческих задания; 696 точных совпадений старых EN/KR переиспользованы.

`scripts/audit_localization_diff.py` рекурсивно сопоставляет файлы и записи по стабильным ID, выявляет отсутствующие и скопированные английские тексты, пустые русские строки, изменения источника, ошибки структуры, подстановок и тегов, технические расхождения. Латинский текст формирует отдельную очередь для проверки; он не считается автоматически ошибкой. Режим `full-review` проверяет весь текущий набор, `diff` — изменения относительно индекса предыдущего обновления. `--check` возвращает ошибку при неразрешённых блокерах.

Пример запуска из корня репозитория:

```powershell
python scripts/audit_localization_diff.py --en "ПУТЬ/Localize/en" --kr "ПУТЬ/Localize/kr" --ru Localize/Limbus-RU-Full --target-version 1.116.1 --mode full-review --report-dir reports/current --check
```

Синхронизация списков с повторяющимися ID исправлена: новая запись больше не сдвигает переводы последующих записей. Повторные вхождения сопоставляются по порядку внутри одинакового ID; неоднозначные пути отклоняются.

54 файла только в KR рассмотрены отдельно, включая пустые файлы, технические привязки и дублирующийся сюжетный материал. Их наличие не скрывается и не приравнивается к отсутствию русского перевода всех английских файлов. Подробности — в [korean_only_review.md](./1.116.1/korean_only_review.md); runtime-статус не выводится по одному имени файла.
