# Limbus-RU-Full 1.118.1-r3

Исправления по сообщениям DMD, Talanyr и Mrpersik1 для версии игры 1.118.1. За основу взят выпущенный архив `1.118.1-r2`. Данные архива и Git сверены после разбора JSON.

## Сюжет, имена и термины

Скриншоты приводят к сценам `E402A`, `E405B`, `E406B`, `E407A`, `E042X`, `S502B` и `S504B`. В `E402A/24` у Фауст стоит нейтральное корейское `오티스 씨`. «Госпожа Отис» сохраняет вежливость обращения и согласуется с другими сценами. В `S514B/106` говорит Измаил, поэтому исправлены обе формы прошедшего времени в её реплике.

В других сценах и справочных текстах подтвердились варианты «Ишмаэль», «Исмаил», «Измаиль», «Аутис» и «Оутис». Имена сверены с `이스마엘` и `오티스` в оригинале, с официальным английским текстом и с прежней локальной терминологией. Для `해결사` восстановлены формы слова «корректировщик» с учётом падежа. В первоапрельской сцене `E001X` исправлены две реплики до обмена телами. Реплика после обмена оставлена по контексту сцены.

## Описания и отображение

- В `Skills_Ego_Personality-12.json`, запись `2120711`, повтор описания на трёх уровнях унаследовал лишнюю точку. Поиск того же дефекта по всему пакету выявил дополнительные случаи в пассивках, эффектах, навыках и событиях. Пунктуация сверена с исходной фразой. Намеренно оборванные названия сохранены.
- В `Personalities.json`, запись `11114`, русское название Отис было одной строкой, хотя в EN и KR оно разделено. После переноса ширина самой длинной строки по метрикам двух шрифтов из архива снизилась примерно с 19–20 до 9–10 em. Реальный размер блока зависит от клиента.
- В навыках и пассивке Чхуноккуна Хун Лу уже существующий ключ `TiedRopeHonglu` был вложен сам в себя внутри дополнительной подписи. Восстановлена запись `[TiedRopeHonglu]`, которую используют оба оригинала. Так же проверены и исправлены вложенные ссылки на два варианта «Татуировок мести». Название эффекта `WindBladeIshmael` согласовано в таблицах навыков и статусов.
- В опубликованном `1.118.1-r2` уже отсутствовали посторонние хвосты вида `(;ID)`. В названных навыках Роди, Измаил и Хитклифа статическая сверка не обнаружила повторов названий эффектов в скобках. Скобки с расчётами, ограничениями и условиями сохранены. Отображение в клиенте остаётся непроверенным.

## Повторная проверка

Скрипт обходит вложенные JSON и выводит кандидатов с именем файла, адресом, ID и соответствующими фрагментами EN и KR. Он ищет варианты имён, термин, согласование в репликах, длинные названия идентичностей, повторную пунктуацию и проблемы со ссылками на эффекты. Совпадения требуют проверки по смыслу и игровой разметке.

```powershell
python scripts/audit_community_feedback.py --ru Localize/Limbus-RU-Full --source "D:/Game/Localize" --report reports/community-feedback.json
```

В корпусе из 2 379 JSON проверено 189 766 непустых полей, подходящих для этих правил. Исправлено 179 полей в 71 JSON. Повторная сверка исходников прошла без блокирующих расхождений, все 73 теста прошли. Проверка отображения в игре не проводилась.
