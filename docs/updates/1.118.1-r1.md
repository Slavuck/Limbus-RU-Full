# Limbus-RU-Full 1.118.1-r1

Хотфикс для Limbus Company 1.118.1. В обновлении русификатора 1.117.1-r1 два варианта перевода реплик попали в поля имён говорящих. Последующие обновления унаследовали эти строки. [Коммит с подменой](https://github.com/Slavuck/Limbus-RU-Full/commit/cbd728cc61548d5602a2209975cfcde1abc61199)

| Запись | Восстановленная подпись |
| --- | --- |
| `StoryData/P11211.json`, `id=37`, `teller` | Старшая Сестра |
| `RPGSystem/rpg-loc-dialogue-floor-b1.json`, `D-1105`, `texts[index=2].speaker` | Данте |

Обе подписи сверены с корейским и английским оригиналами. В пакете изменены только эти два поля. В аудит добавлена проверка полей имён. Она помечает подозрительно длинные подписи с пунктуацией предложения для сверки с оригиналом.

Полный аудит 2 379 JSON воспроизвёл обе подмены на пакете 1.118.1. В исправленном дереве обязательных расхождений нет. Проверка была статической.
