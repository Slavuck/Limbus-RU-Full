# Обновление 1.117.1 — 22 октября 2026 года

База — опубликованный русификатор **1.117.0-r1** от 18 октября, включающий обновление от 16 октября и исправление пассивки И Сана. Инфраструктура параллельного редакторского обновления не изменялась; работа выполнена в отдельной папке выпуска и `output/Limbus-RU-Full`.

## Автоматическая проверка

Добавлен `scripts/audit_current_localization.py` — удобный запуск существующего рекурсивного аудита с полной проверкой и ненулевым кодом при обязательных расхождениях. Он проверяет файлы, ID и поля, новые/удалённые строки EN/KR, отсутствующий и скопированный текст, теги, подстановки, разметку, технические значения и устаревшие русские записи. Оригиналы и перевод не меняет.

```powershell
python scripts/audit_current_localization.py --source <папка_Localize_игры> --ru Localize/Limbus-RU-Full --version 1.117.1 --baseline-dir <предыдущий_аудит> --report-dir <новый_аудит>
```

Для запуска без предыдущего среза опустите `--baseline-dir`. Папка предыдущего аудита должна содержать `source_index.jsonl` и `source_manifest.json`; сохранённые `queues/` используются при наличии. Проверенные названия сезона, сочетание клавиш, буквенные метки и намеренно искажённые строки сохранены с явными решениями, доступными в [review_decisions.jsonl](./1.117.1/review_decisions.jsonl).

Итоговый аудит: **2370 EN, 2413 KR, 2370 RU JSON**, 271611 исходных строковых полей, 86113 полей в области полной проверки. **0** ожидающих решения, пропусков, непереведённых строк, ошибок тегов, подстановок, разметки, технических значений и устаревших русских записей. Сводка: [full_summary.json](./1.117.1/full_summary.json). Хеши всех исходных файлов повторно проверены перед упаковкой: исходники не менялись во время работы.

Полный индекс и очереди для следующего обновления сохранены локально в `work/release-1.117.1/after/`; в GitHub публикуются компактные отчёты и манифест исходных файлов. Исходные JSON не дублируются в публичной документации.
