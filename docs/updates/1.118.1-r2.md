# Limbus-RU-Full 1.118.1-r2

В третьем эпизоде пролога карточки знакомства берут текст из `IntroduceCharacter.json`. Официальные `EN_IntroduceCharacter.json` и `KR_IntroduceCharacter.json` содержат ручные переносы. При редактуре `1.117.1-r1` шесть русских карточек сократились с 9–10 строк до 4–6, а отдельные строки стали существенно шире. У Грегора ширина самой длинной строки выросла примерно с 36 до 94 em по метрикам шрифта из архива. [Коммит с регрессией](https://github.com/Slavuck/Limbus-RU-Full/commit/cbd728cc61548d5602a2209975cfcde1abc61199)

Переносы восстановлены у Фауст, Дон Кихот, Роди, Синклера, Отис и Грегора. Слова и разметка карточек сохранены. После правки каждая карточка занимает не более девяти заданных строк. Максимальная ширина среди шести исправленных карточек составляет 42,3 em, а среди шести остальных — 46,2 em. Метрики рассчитаны по `PretendardVariable.ttf` из пакета с учётом жирных фрагментов. Эти значения сравнивают строки между собой. Фактический размер блока в игре зависит от клиента.

По всему пакету сопоставлены переносы в EN, KR и RU. Дополнительно проверены изменения 1 838 JSON из коммита с регрессией. В семи окнах событий и обучения восстановлены переносы, подтверждённые оригиналами. В событии Зеркального подземелья `901027` возвращены четыре пропавшие строки и перенос в слитной фразе. Остальные длинные строки встречаются в разных компонентах интерфейса. По данным локализации нельзя определить, где клиент переносит или прокручивает такие строки.

В архиве изменены 14 полей в девяти JSON. Структурная сверка прошла по 2 379 JSON без блокеров, пройдено 70 тестов. Проверка отображения в клиенте не проводилась.
